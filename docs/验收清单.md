# 快读 · 手动验收清单

> 自动化只能锁住纯函数（22 个 vitest 用例已绿）；扩展行为按本清单人工过一遍。
> 建议顺序：M1 三类页面 × 中英文 → M2 端点 → M3 动作 → M4 引导/边界。

## M0 安装

- [ ] `npm run build` 无报错；`chrome://extensions` 加载 `dist/` 成功，无错误横幅
- [ ] 工具栏出现纸墨风图标；首次安装自动打开设置页
- [ ] `chrome://extensions/shortcuts` 里能看到「快读当前页面 Alt+Shift+S」

## M1 正文抽取（每类页面 × 中英文各一遍）

| 页面类型 | 样例 | 期望 |
|---|---|---|
| 新闻长文 | 任门户深度报道 / BBC 长文 | 标题干净、正文完整、无导航残留 |
| 文档站 | MDN / React docs | 正文准确，侧边栏目录不被混入 |
| SPA 信息流 | 知乎回答 / 微信公众号 | 能抓到回答正文（回退链生效也不报错） |

- [ ] 加载中的骨架屏先显示「正在抓取正文…」，抓到后显示《标题》· N 字
- [ ] 登录页 / 搜索页 / `chrome://settings` → 友好报错「不是文章 / 不能快读」，不崩
- [ ] PDF 链接 → 提示 v1 不支持

## M2 LLM 接入

- [ ] 首次使用弹引导卡：选智谱预设 → 填 Key → 「测试连接 · 通过后保存并开始」
- [ ] 点保存时弹一次 `open.bigmodel.cn` 的授权框；**点拒绝 → 保存失败有明确文案**
- [ ] 通过后自动开始摘要，3-8 秒出卡片
- [ ] 错 Key → 「API Key 无效」；断网 → 「连不上端点」；限流 → 自动重试后给明确文案
- [ ] 设置页改模型名（如换 Groq）保存后立即生效

## M3 卡片与动作

- [ ] 卡片要素齐：标题（≤3 行截断）/ TL;DR / 3-5 要点 / 盖章（三态颜色对）/ 关键词 / 金句
- [ ] 复制 MD：贴进笔记软件格式正确（标题/引用/列表/关键词/原文链接）
- [ ] 存 PNG：图片 2x 清晰（发手机上字不糊），文件名 `快读-站点-日期.png`
- [ ] 朗读：中文发音自然；暂停/继续/停止可用；调速率立即生效
- [ ] ⭐ 收藏 → 历史页顶部出现「已收藏」分区；再点取消
- [ ] 历史：≥2 条记录可回看（点开只读卡片）、单条删除、清空有确认

## M4 引导与边界

- [ ] 清空全部数据后重开弹窗 → 重新出现引导卡
- [ ] 设置页隐私三句可见；当前端点域名正确显示
- [ ] 导出 JSON 打开检查：Key 已打码
- [ ] 让朋友拿 zip 走完 README 安装 + 配置，目标 5 分钟内出第一张卡
