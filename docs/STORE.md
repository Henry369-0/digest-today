# 快读 · Chrome Web Store 上架材料（v1.0.0）

## 商店名称

快读 — 网页摘要卡片机（≤45 字符 ✓）

## 简短描述（≤132 字符）

在任意网页一键生成摘要卡片并朗读：一句话总结 + 要点 + 盖章结论 + 关键词。自带 Key，数据不出本机。

## 详细描述

快读（digest.today）——读长文前先花 8 秒问一句：值得一读吗？

在任意文章页按 Alt+Shift+S（或点扩展图标），自动完成：
① 抓取正文（Readability 引擎，浏览器阅读模式同款）
② 调用你自己配置的 LLM 端点生成摘要
③ 输出一张复古纸墨风摘要卡片：一句话总结、3-5 条要点、"值得一读吗"盖章、关键词、原文金句

卡片可一键复制为 Markdown（直接贴进笔记）、导出 2x 高清 PNG（社交分享）、中文朗读（可调速），还支持收藏——攒着做你的每周阅读复盘。

隐私是硬设计，不是口号：
· 不带任何内置 Key、没有后端服务器，LLM 端点由你自己配置（智谱 GLM-4-Flash 免费档 / Groq / OpenRouter 免费模型 / 本地 Ollama / 任意 OpenAI 兼容地址）
· API Key 与历史记录只存本机
· 平时不读任何页面：只在按下快捷键那一刻获得当前标签页的临时权限
· 保存端点时才请求那一个域名的访问授权，拒绝就保存失败

手工作坊系列第三件，与「穿几层」「番茄年报」同套复古纸墨视觉。

## 隐私政策（商店审核用三句 + 展开）

三句版（设置页同款）：
1. API Key 只存本机（chrome.storage.local），开发者没有服务器。
2. 文章正文只发送给用户自行配置的 LLM 端点（设置页明示当前域名）。
3. 历史记录只存本机，可随时一键清空或导出（导出文件不含 Key）。

展开版：本扩展不收集、不传输任何用户数据到开发者侧；不包含分析/追踪代码；权限最小化（activeTab/scripting/storage），host 权限按端点运行时申请；数据删除方式为设置页"清空全部"或直接卸载扩展。联系方式：填写你的邮箱。

## 审核要点自述（single purpose / 权限说明）

- 单一用途：为当前浏览的文章生成摘要卡片并朗读。
- activeTab + scripting：仅在用户主动触发（点击图标/快捷键）时向当前标签页注入正文抽取脚本；不声明常驻 host 权限。
- storage：保存用户设置与最近 30 条摘要历史，仅存本机。
- optional_host_permissions (http/https)：仅当用户保存其 LLM 端点时，请求该端点域名的访问权（用于从扩展发起 fetch），拒绝则保存失败。
